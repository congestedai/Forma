# Temas do Forma

## Incluídos no aplicativo

Claro orbital, Vazio profundo e Tempestade solar já acompanham o Forma. Estão disponíveis no seletor de tema, sem download separado.

## Pacote extra de apoio

Titânio, Papel técnico, Nebulosa, Bosque e Alto contraste estão no pacote para baixar pelo [Patreon do Forma](https://www.patreon.com/c/FormaCAD), incluído nos níveis de US$ 5 e US$ 40. Os arquivos extras não são hospedados neste repositório público.

1. Baixe e extraia o ZIP do post no Patreon.
2. Abra a biblioteca de temas do Forma.
3. Use **Importar temas** e escolha o arquivo .forma-themes.json para importar o pacote, ou um .forma-theme.json para importar somente um tema.
4. Clique em **Usar** no tema escolhido.

São arquivos pequenos de cores, sem imagens, plugins ou código executável. Os temas ficam no perfil local do Forma. Use **Exportar biblioteca** para guardar um backup ou transferir seus temas. O aplicativo não exige login no Patreon para importar ou usar esses arquivos. Temas obtidos regularmente continuam funcionando offline após cancelar o apoio; o acesso a novos pacotes segue as condições do nível.
